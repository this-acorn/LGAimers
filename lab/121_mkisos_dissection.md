## 3. ★ 이식 후보 순위 (LB로 실증 + 우리에게 없는 것만)

**먼저 산수 하나 정정**: Score = 1e5·(1 − B/B₀)이고 B₀는 같은 test set의 r(1−r)로 고정이다. 따라서 **"그들 base가 낮으니 이득을 할인해야 한다"는 틀렸다** — 보정이 우리 예측에 대해서도 같은 ΔBrier를 만든다면 LB 점수 이득은 그대로다. 할인 사유는 **오직 중복(우리 백본이 이미 흡수)** 하나뿐이다. 아래 기대치는 중복만 반영했다.

---

### T1. 후보 혼합 — 단, **제출 전에 K를 계산으로 판정**  (비용: 0시간, 재학습 없음)

- **메커니즘**: `S(w) = (1−w)S₀ + wS₁ + w(1−w)K`, `w* = 0.5 + d/(2K)`, `gain = (d+K)²/(4K)`. 이 항등식이 build_exp040_public_geometry_candidate.py:106-118에 글자 그대로 존재하고, build_exp048은 5꼭짓점 simplex로 일반화했다.
- **그들 LB 실증**: strict 1043.6074197937 + aggressive 1043.1871309639 → 50:50 **1045.1827084551**, 두 단독 대비 **+1.5753 / +1.9956** (SUBMISSION_LOG.md:320). 실측 곡률 **K = 4×(1045.1827084551 − 1043.3972753788) = 7.1417**. 이 대리모형으로 미제출 3-way를 예측 1044.4441 → 실측 **1044.4711**, **오차 −0.027점** (EXP-048 JSON → public_geometry.scenarios.2024.threeway_reconstruction_error).
- **우리 기대치**: 항등식은 우리 것과 동일하므로 새 지식은 **"LB 외삽 오차가 0.03~0.09점"**이라는 정밀도 인증뿐. 우리 후보쌍은 d = 1081.67 − 1092.81 = **−11.14**. gain > 0이려면 K > 11.14가 필요하고, gain ≥ 3점이려면 대략 K ≥ 30이 필요하다. 우리 두 후보는 **같은 CatBoost 백본**이라 그들 K=7.14 쪽에 가까울 위험이 크다.
- **행동**: `lab/`의 .npy로 `K = (1e5/B₀)·E[(p₁−p₀)²]`를 **즉시 계산**(5분, 학습 0, 슬롯 0). 감쇠비는 두 팀 표본(그들 K_LB/K_local = 7.1417/9.537 = **0.749**, 우리 117.51/191.3 = **0.614**)에서 **0.65를 보수 기본값**으로 쓰고 하한 0.6으로 판정. **gain 추정 < 3점이면 제출하지 말 것.** 그들 dualrank가 약한 branch를 섞어 −0.71을 맞은 사례가 경고다.
- **규정 위험**: 없음. **사망 목록 관계**: 없음(재가중은 새 축이 아님).

### T2. EXP-064형 (count × 주자수 × 확률bin) 안정셀 EB + **common-sign 게이트**  (비용: 1~2시간, 재학습 없음, 슬롯 1)

- **메커니즘**: `pbin = clip(int((p_base − 0.35)/0.025), 0, 12)`, 셀키 = (count_index = 4·balls+strikes, num_runners_on, pbin), smoothing k=500, `effect = Σresid/(n+k)`, clip ±0.02, 가중 **0.50** 가산. **핵심은 게이트**: 2021~2024 **모든 source 시즌에서 nonzero이고 부호가 같은 셀 95개만** 채택.
- **그들 LB 실증**: **1049.0406115485**, base EXP-051 대비 **+1.0615** (SUBMISSION_LOG.md:377). 로컬은 2023이 base 930.21보다 낮아 hard gate **실패**(EXPERIMENT_LOG.md:67, 882.62).
- **우리 기대치 (하향)**: 이건 우리 사후 아핀(전역 1차식)의 **비모수 확장판**이다. 우리 아핀이 이미 **+22.6**을 가져갔다는 것은 전역 성분이 소진됐다는 뜻이므로, 남은 셀별 잔여분은 **+0 ~ +1.5** 범위로 본다. 그들 +1.06보다 클 이유가 없다.
- **평가 규칙(필수)**: 독자 2가 잡은 함정 — 그들 temporal TE는 **raw +6.07인데 아핀 보정 후 −14.20**(EXP-014 JSON: TE-off 726.24/780.47 vs TE-on 732.31/766.27). 우리도 반드시 **아핀 이후**로 증분을 재고, `lab/104_cat5_y{2022,2023}` + `lab/89_cat5`(2024)로 **연도별 부호 일치**를 확인할 것.
- **규정 위험**: 낮음. 표를 **train 과거 시즌 라벨만으로** 만들면 행독립 유지. 단 `pbin`이 자기 예측값의 함수라 각 행이 자기 p만 보므로 행간 위반 아님.
- **사망 목록 관계**: `count_hand` 조합 categorical(LB −10.1)과 **키가 다르다**(count×주자×확률bin, hand 없음). 다만 인접하므로 common-sign 게이트를 통과 못 하면 즉시 폐기.

**부수 가치(무료)**: common-sign 필터는 **우리 hand delta 사고의 사후 검사기**다. 우리는 "로컬 4/4 연도 양수 평균 +16.8" → LB −22.2였는데, 그때 **모든 연도 부호 일치 + nonzero**를 요구했다면 걸렸을지 `lab/90_analysis_2024.parquet` + 연도표로 학습 없이 확인 가능(2분). 앞으로 만드는 모든 조건부 표의 기본 게이트로 채택 권고 — **비용 0, 위험 0**.

### T3. EXP-072 투수 잠재 제구력 AR(1) — **상관 사전검사 통과 시에만**  (비용: 2~3시간, 재학습 없음, 슬롯 1)

- **메커니즘**:
  1. 선수×시즌 성공률을 k=200으로 축소한 league-centered log-odds 상태 s(p, season).
  2. **검증 시즌보다 앞선 연속 시즌 pair만**으로 zero-intercept AR(1) ρ를 ridge=1.0, 범위 [0,1]에서 적합.
  3. 마지막 관측 시즌과의 간격만큼 `ρ^gap` 감쇠 → `prob = sigmoid(league_logit + latent·ρ^gap)`.
  4. 현재 시즌 진행분(asof 누적 − 동결 과거 career)과 k=30으로 결합:
     `dynamic = (season_succ + 30·prob)/(season_n + 30)`, `global = (season_succ + 30·league)/(season_n + 30)`
  5. `correction = (dynamic − global) × 0.50`. 신규/미관측 투수는 0.
  - 적합된 ρ (내가 JSON 직접 확인): 2021 **0.35726**, 2022 **0.37705**, 2023 **0.44973**, 2024 **0.36325** (artifacts/EXP-072/dynamic_pitcher_state/validation_metrics.json → folds.{s}.state_audit.rho).
- **그들 LB 실증**: **1053.5585249357**, base 대비 **+5.5794**, 그들 2위 (SUBMISSION_LOG.md:379). 로컬 2024 883.01(README.md:91)로 base 880.23 대비 +2.78 — hard gate는 통과 못 했는데 **LB는 올랐다**. 이 방향(로컬 약함 → LB 강함)은 우리 "로컬 반전" 규칙과 부호가 맞다.
- **우리 기대치**: **+0 ~ +3, 중복 위험 매우 큼**. 이유 두 가지 — (a) 4단계의 `dynamic − global` 은 우리 **CS 시즌진행분 11피처(LB +92)**와 정보원이 완전히 동일하고, (b) 우리 **V18 잔차가 이미 (game_type, pitcher) 루트**에서 같은 투수 축을 γ=0.30으로 건드린다. 그들에게만 있는 순수 신규분은 **ρ^gap로 감쇠된 잠재값을 EB의 prior 자리에 넣는 것** 하나다.
- **필수 사전검사(학습 0, 30분)**: `lab/89_cat5_probs_seed{42,7}.npy`(2024)로 **V18-적용 후** 잔차 `y − p'`와 이 correction의 **상관 및 연도별 부호**를 본다. EXP-105가 준 판정 기준 그대로: 상관이 아니라 **target(y−p)과의 정렬 + 부호의 시즌 안정성**이 기준. V18 correction과의 상관이 0.3 이상이면 **기각**.
- **규정 위험**: 낮음. train 2019~2024만 사용, 행독립. 단 **2025 신규 투수는 effect=0** — 우리 신인 구간은 이미 두 번 실패한 축(신인 전용 d=−51.8)이라 미보정 구간이 남는다.
- **사망 목록 관계**: '시즌가중 0.9^age + lr0.04 (LB −27.6)'과 **시간감쇠라는 점에서 인접하나 다르다** — 우리가 죽인 건 **학습 샘플 가중** 감쇠, 이건 **prior 감쇠**다. 그래도 인접 경보로 취급.

## 5. 규정 관점 특이점

1. **후속행 키 조회 라벨 복원** — `(pitcher_id, season, asof_pitcher_n)` → `n+1` 행을 keyed lookup(파일 순서 무관)해 `asof_*_rate × n`의 정수 증분으로 현재 투구의 outcome/구종을 복원. 1,475,092행 중 **1,472,040행 유효, control_success mismatch 0건**(README.md:127), 구종 one-hot 오차 0(1,472,832행, :128). **train 전용이라 합법** — test에는 후속행이 없어 설계상 자동 비활성. 우리 5클래스/구종 복원과 동일 원리이며, **우리 라벨 구성이 독립적으로 재현·검증된 셈**이다.
2. **행독립성 6케이스 QA 매트릭스** — batch / singleton / reverse / random permutation(seed 42) / split batch / duplicate batch, tolerance 1e-12, 실측 max abs diff **0.0** (qa_exp110_candidate.py:32-75). **우리 `candidate_v18g030.zip`에 이 매트릭스 기록이 없다면 실격 리스크 대비로 마감 전 30분에 복제 권고**(개념만, 코드 복사 금지).
3. **canonical test 미개봉** — 빌드·QA 전 과정에서 `data/test.csv`·`sample_submission.csv`를 한 번도 열지 않고 train에서 만든 6행 fixture로만 스모크. metadata `canonical_test_or_sample_opened: false`.
4. **LB 결정론 확증** — EXP-058이 **동일 ZIP을 두 번 제출해 Public이 소수점 10자리까지 동일**(1047.8300661031, SUBMISSION_LOG.md:344-345, README.md:130). → **우리 LB 궤적의 +11.1(V18), +17.8/+22.6(아핀)은 측정 노이즈가 아니라 실제 신호**이며, 3점 곡선으로 아핀을 결정한 절차가 정당화된다. 이 항목 하나가 이번 감사의 최대 소득일 수 있다.
5. 제출 구조: script.py 847줄 + requirements.txt **`lightgbm==4.6.0` 한 줄**, HGB를 JSON 직렬화 후 순수 numpy로 재구현 추론, ZIP 4.8MB, 서버 실행 **12~17초**. 우리 8시드 CatBoost 대비 여유가 크다(우리 10분 제한은 문제없음).

### 하지 말 것 (근거 명시)

- ❌ **TrackMan 재개** — 그들은 커버리지를 49%→78%까지 늘리고도 LB 순증이 EXP-051의 **+0.99**가 전부였고, 물리는 **−1.21 / −3.91**이었다. 우리 커버리지는 더 낮다. **커버리지가 병목이 아니었음이 남의 비용으로 증명됐다.**
- ❌ **로컬 폴드로 혼합 가중/잔차 가중 적합** — 그들 strict prior-fold minimax가 2023에서 **−72.83**. Ridge 합성 4종 전패. w는 **사전 고정 상수**로만(그들이 성공한 EXP-051/063/071/072 전부 .10/.25/.50 고정).
- ❌ **로컬 2024 Skill로 후보 거르기** — 그들 LB 실측 7점 중 로컬 상위 5점의 pearson **0.076**, **로컬 최고 883.31(EXP-053)이 LB는 뒤에서 두 번째**. 판정 기준은 "정보 구조가 바뀌었는가"이지 로컬 점수가 아니다.
- ❌ **아핀 계수 변경** — 유일한 반대 증거는 그들 base_exp051의 진단 캘리브레이션 기울기 단조 감소 **2021 1.1798 → 2022 1.1504 → 2023 1.0396 → 2024 0.9897**(EXP-072 JSON, 내가 직접 확인)이다. 그러나 (a) 그들 백본은 우리와 분산 구조가 다르고, (b) 우리 1.06은 **LB 3점 곡선**으로 잡은 것이라 증거 등급이 훨씬 높으며, (c) 오히려 그들 2024 `mean_gap = +0.005227`(예측이 실제보다 높음)은 **우리 −0.0066 중심 이동과 부호가 같아 지지 증거**다. 결론: **건드리지 말 것.** 만약 순수 재조정에 슬롯 1개를 쓴다면 1.06을 **올리는** 방향은 이 증거와 반대다.

### 정직한 총평

이 저장소는 **우리보다 39점 아래**이고, 그들 자신도 EXP-060 convex oracle 상한(2023 942.77 / 2024 897.27)으로 "현재 신호 재가중으로 1000 불가"를 인증한 뒤 연구를 종료했다. **여기서 우리 1092.81을 크게 밀어올릴 카드는 없다.** 실행 가능한 3개(K 계산, 셀 EB, AR(1))의 합리적 기대치는 낙관해도 **+0~+4점**이고, 셋 다 우리 아핀·CS·V18과 중복 위험이 크다. 반면 이번 감사의 확실한 소득은 방어 쪽이다 — **LB 결정론 인증**, **γ=0.30의 구조적 정당성**, **로컬-LB 무상관의 외부 확증**, **common-sign 게이트**, **행독립 QA 매트릭스**. 남은 32시간은 새 축을 파는 것보다 **1092.81을 안전하게 지키고, 계산으로 판정 가능한 것만 슬롯에 태우는 데** 쓰는 편이 기대값이 높다.
