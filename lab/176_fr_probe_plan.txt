Exact geometry
--------------
For either g in {F,R}, write

    S_g(w) = S0 + L_g w - K_g w^2.

Let H_g = S_g(0.5)-S0 and d_g = S_g(1)-S0.  The two leaderboard
measurements recover

    d_g = S_g(1)-S0,
    K_g = 4 H_g - 2 d_g,
    L_g = d_g + K_g,
    w*_g = L_g/(2 K_g),                 if K_g > 0,
    peak gain_g = L_g^2/(4 K_g).

Check: S_g(w)-S0 = (d_g+K_g)w-K_g w^2.

For the normalized Brier metric, the quadratic cross term is proportional to
sum_i vF_i*vR_i.  Every product is zero because row support is disjoint.
Therefore, with no nonlinear postprocessing,

    S(wF,wR) = S0 + gain_F(wF) + gain_R(wR),

and the two one-dimensional optima are also the exact joint optimum.  No
fifth calibration score is mathematically needed.

Clipping boundary and required response
---------------------------------------
For an endpoint pair A_i and T_i, v_i=T_i-A_i.  A single quadratic remains
valid at weight w only while every affected real test row satisfies

    epsilon <= A_i + w v_i <= 1-epsilon.

The certified interval is the intersection of those inequalities across the
affected rows.  The default [0,1] interval is safe whenever both endpoint
probabilities already lie inside the output bounds, because it is a convex
combination.  Extrapolation w<0 or w>1 is not automatically safe.

Once clipping activates, row support remains disjoint, so F/R additivity is
still exact.  However, each one-dimensional score becomes piecewise rather
than one global parabola as its active clipped-row set changes.  Consequently:

* never report L^2/(4K) as an achievable score outside a certified affine
  interval;
* clamp to the certified interval for the guaranteed candidate;
* use any extra probe as a final-worthy clipped candidate, not as enough
  evidence to reconstruct an unknown piecewise curve;
* compute clipping thresholds only from the real test predictions produced
  by the submission endpoints.  Do not use fabricated test labels or fake
  test geometry.

---------------------
* K>0: the curve is concave and has an interior unconstrained vertex.
* K approximately 0: the two measurements imply a near-linear curve; choose
  a bound, because the vertex estimate is numerically unstable.
* K<0: maximize only over stated bounds and audit score transcription,
  clipping, and package consistency.  Do not trust an unconstrained vertex.
* Use the full official score precision.  Rounding S(0.5) and S(1) can badly
