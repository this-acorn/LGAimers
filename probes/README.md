# Calibration and blend probes

Focused experiments used to select calibration settings and ensemble weights.

| Probe | Purpose |
| --- | --- |
| Probability shift and scale | Adjust prediction bias and spread. |
| Residual strength | Measure the contribution of learned corrections. |
| Endpoint mixtures | Test whether prediction pipelines complement one another. |

See [methodology](../docs/METHODOLOGY.md#calibration-and-ensembling) for the analysis and [usage](../docs/RUNNING.md) for execution.
