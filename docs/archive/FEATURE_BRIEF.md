## 1. 과제 한 줄 요약

야구 투구 **직전까지의 정보만으로** 그 투구의 제구 성공(0/1) 확률을 예측.
지표는 Brier Score(=확률의 MSE) 기반 → **점수 = 100000×(1−Brier/기준Brier)**.
train 147.5만 행(2019~2024), test 24.6만 행(2025, 비공개). 신호가 매우 약한 문제
(BSS ~0.7% 수준)라서 피처 하나가 리더보드 수십 점을 좌우한다.

**현재 성적**: 리더보드 830.32 (1위 1421.99, 격차 -592) · hand delta 반영 제출 예정(예상 ~847)

## 2. ★ 가장 중요한 규율 — 노이즈 바닥

시드만 바꿔도 점수가 σ≈15.3 흔들린다. **모든 피처 아이디어의 가치는 실측으로만 판정**하며:

| 측정 방식 | 유의 임계 |
|---|---|
| 단일 학습 | 30점 |
| 4시드 앙상블 | 15점 |
| 8시드 앙상블 비교 | 15점 (2σ) |
| 임계 근처 회색지대 | **선택에 안 쓴 독립 시드로 재측정** (이 절차로 두 번 결론냄) |

로컬 검증(2019~2023 학습→2024 채점)이 리더보드를 전이율 0.958로 예측한다.
→ 아이디어 세션에서는 "이게 몇 점일까" 추측에 시간 쓰지 말 것. **가설의 구조**가 좋은지만 논하라.

## 3. ★ 피처 가치의 제1원리 (실측으로 확립됨)

**"트리가 구조적으로 못 하는 계산만 가치가 있다."**

### 가치 있음 (실측 근거)
1. **행을 가로지르는 선수 단위 조건부 집계** — 트리는 행 집계를 절대 못 한다
   - `f_same_hand` 등 G2 매치업: **+107** (역대 최대 단일 개선)
   - 투수/타자별 손 매치업 이력 delta: **+17.5** (2026-08-23 채택, 독립 3회 재현 +13.9/+17.5/+22.9)
2. **A==B 비교, A−B 차이** — 단, 매치업 정보와 엮일 때만

### 무가치 (전부 실측으로 사망)
- 단조변환(log 등): 트리는 단조변환 불변
- 결측 플래그: GBDT가 NaN 네이티브 처리 (효과 정확히 0.0)
- 기존 컬럼 재조합/상호작용(balls×3+strikes, li×경험 등): 트리가 스스로 조합한다
- 볼카운트 파생 행 단위 피처 (LOO -13.1)
- 베이지안 스무딩 피처 추가 (+3.3 노이즈)

### 죽은 축 (재제안 금지)
- 시즌 드리프트 보정 (정직한 4종 전부 마이너스, 반칙 상한조차 +51)
- 확률 보정 Isotonic/Platt (실전 곡선은 이미 깨끗함 ECE 0.0106, 보정기 모델간 전이 -150.9 유해)
- XGBoost 앙상블 혼합 (이득 0.0 — 같은 방식으로 틀림)
- 하이퍼파라미터 (용량·잎 개수 축 포화)
- 압박 상황(클러치) 선수별 delta — 야구 연구상 불안정 스킬이라 보류 (기각 아님, 후순위)

## 4. 사용 가능한 원재료

### train/test 공통 컬럼 (48개, test에는 target 없음)
- 경기: season, game_month, game_dayofweek, inning, top_bottom, game_type
- 카운트/점수: balls_before, strikes_before, outs_before, run_top/bot/total_before, score_diff_home, score_diff_pitcher_team
- 주자/중요도: runner_on_1b/2b/3b, num_runners_on, base_state, home/away_win_expectancy, li
- 선수/팀: pitcher_id(792명), batter_id, pitcher_hand(2=우,1=좌), batter_hand, pitcher_team_id(13개), batter_team_id
- asof_* (주최측 사전계산, 투구 직전 시점 누적): 투수 n/성공률/reverse/middle/ball/strike rate,
  최근 1·3·5경기 성공률/middle rate, 타자 n/성공률/middle rate, 구종믹스 n/fastball/breaking/offspeed rate
  - ⚠️ asof_pitcher_pitchmix_n == asof_pitcher_n (100% 동일, 실측)

### trackman_history.csv (179만 행, 2019~2024) — ★ 이제 쓸 수 있다
- 구종(tagged/auto/group), 구속(rel_speed/zone_speed), 회전수, 무브먼트(수직/수평),
  릴리스(extension/rel_height/rel_side), 경기일자/월/요일, 이닝, 카운트
- **ID 체계가 달라 직접 조인 불가였으나, 지문 매칭으로 뚫었다**:
  - `lab/trackman_match_v3.csv` — 투수 325명 매칭 확정 (train 투구량의 71.3% 커버)
  - 방법: 1군 필터(팀코드 11개, MIN_*=2군 제외) + 좌우 블록 + 월×요일 등판패턴 + 팀 궤적
  - 팀 대응: 12=두산 13=LG 14=키움 15=롯데 16=KIA 17=한화 18=삼성 19=NC 20=KT 21=SSG(SK 통합)
  - 주의: trackman은 1군 투구의 ~80%만 커버(구장별 장비 차, KIA 최소) / 느슨한 매칭 꼬리엔 오매칭 가능성
- **미개척 신호**: asof_*는 전부 "결과" 통계인데 trackman은 "원인"을 준다 —
  릴리스 포인트 일관성(rel_height/rel_side의 std = 제구력의 역학적 지표), 구속 수준/하락 추세,
  회전수, 무브먼트 크기, extension. 타자 쪽(batter_trackman_id)은 아직 미매칭.

### 시간 안전성 설계 패턴 (검증 완료, 재사용 가능)
- **시즌 단위 as-of**: (선수, 시즌, 조건)별 누적합에서 자기 시즌 몫을 빼는 cumsum 로직 —
  토이 실행으로 누수 없음 증명됨 (exp/15의 `hand_history_table`)
- **배포 테이블**: test 2025용은 전체 train 합계 = "자기 이전 전부" (exp/07의 `deployment_table`)
- train에 경기 날짜가 없으므로 투구 단위 as-of는 자작 불가 (시즌 단위가 한계)

## 5. 대회 규칙 (피처 설계 시 절대 제약)

- **test 행 간 정보 사용 = 실격**: test 내부 집계/분포/누적/rolling/target encoding/사후 보정 전부 금지
- 허용: train(+trackman ≤2024)으로 사전 계산한 값을 각 test 행에 **행 독립 조인**
- 새 피처는 "그 투구 시점 이전 정보만" — 로컬 검증(2024 채점) 시에는 ≤2023 정보만 붙여야 함
- 외부 데이터 금지 / 2025 trackman 없음(존재하지도 않음)

피처 = 원본 47 + G1 볼카운트 5 + G2 매치업 3 + G3 스무딩 4 + G4 최근폼 3 + G5 투타차 1 + G6 결측플래그 2 + **hand delta 2 (신규)**.

## 7. 검토 대기 중인 후보 (우선순위 순, 아직 미실험)

1. **trackman 릴리스 일관성/구속 피처** (exp/17 예정) — 매칭 투수의 시즌 as-of
   rel_height/rel_side std, 구속 평균/추세 등. "원인측" 신호라 asof 성공률과 겹침이 적을 가능성
2. **CatBoost + 선수 ID 범주 직접 투입** — ordered target statistics가 선수 조건부 통계를
   모델 내장으로 생성 (누수 없는 시간순 인코딩). HistGB와 정보 경로가 달라 혼합 후보.
   혼합 전 OOF 오차 상관 ρ 먼저 측정할 것 (ρ 높으면 헛수고 — XGB의 교훈)
3. **투수별 카운트 조건부 delta** — 3볼/2스트라이크 상황의 본인 성공률 편차.
   클러치(심리)와 달리 "카운트별 접근 전략"은 안정적 스킬이라는 가설. hand delta와 같은 코드 패턴
4. 타자 쪽 trackman 매칭 확장 (batter_trackman_id는 아직 손 안 댐)
5. 팀 단위 as-of 성공률 (포수진 대리) — 약한 후보
