## 1.8 ★★ 혼합 축은 (지금은) 닫혔다 — exp/73, 재학습 0, 08-26

```
혼합 항등식:  S(blend) = Σ wᵢSᵢ + Σᵢ<ⱼ wᵢwⱼKᵢⱼ ,  Kᵢⱼ = (100000/DEN)·E[(pᵢ−pⱼ)²]

★ 환산율 라벨 정정: HANDOFF 구판의 "로컬/2025 비율 0.614"는 방향이 헷갈리게 적혀 있었다.
  정확히는  K_2025 = 0.614 × K_local   (즉 K_local/K_2025 = 1.628).
  실측: K_local(CB65,CS79)=191.3, K_2025=117.51 → 191.3/117.51=1.628. exp/63의 계산은
  숫자상 옳았다(1003.05 재현됨) — 틀린 건 문장 라벨뿐이다.

배포 완료 4모델의 2025 최적 혼합 (LB 단독점수 실측 + K 환산):
  CS76+CS79  w=0.47 → 1003.00 (+9.4)     CS79+MC  w=0.06 → 1034.14 (+0.15)
  4모델 최적: CS76 .06 / CS79 .02 / MC .92 → 1034.24  (MC 단독 1033.99 대비 +0.25)
```
**결론: 지금 가진 모델끼리 섞는 것은 무의미하다.** 이유는 두 가지가 겹쳐서다 —
① MC가 나머지를 40점 이상 앞서 최적 가중이 0.92로 쏠린다 ② 전부 같은 CatBoost·같은
피처 계열이라 K2025가 42~50에 불과하다 (CB65와의 K는 117이지만 CB65가 135점 약하다).

**따라서 혼합으로 점수를 얻으려면 "좋은 모델"이 아니라 "K가 큰 모델"이 필요하다.**
CB65가 K=117을 만든 이유는 피처셋 자체가 달랐기 때문이다(65 vs 79). 다음 혼합 후보는
점수보다 **다양성 D를 먼저 보고** 고를 것. submit15(3-way, 예상 1003)는 **폐기** —
MC 1033.99 아래라 제출 가치 없음.

## 1.9 ★★★ 시드 스케일링 — 프로토콜의 두 번째 구멍 (exp/74, 08-26)

**모든 로컬 비교는 2시드인데 제출은 전부 8시드다. 그런데 앙상블 이득은 모델마다 다르다.**

```

## 1.12 ★★★ 혼합의 닫힌 해 — "우리는 단일모델인가"에 대한 답 (exp/77, 08-26)

**그렇다.** submit14 = CatBoost MultiClass **한 설정 × 시드 8개**다. 감사 결과 8개 모델은

정상 작동한다. 하지만 그건 **분산 감소**지 **모델 다양성**이 아니다.

### 2모델 혼합 이득의 닫힌 해 (근사 아님)
```
S(w) = (1−w)S₀ + wS₁ + w(1−w)K   를 w 로 최적화하면

    gain = (d + K)² / (4K),      w* = 0.5 + d/(2K)   (0..1 클립)
    d = S_파트너 − S_챔피언,     K = (1e5/DEN)·E[(p₁−p₂)²]

n개 균등혼합:  gain = K·(n−1)/(2n)     → n→∞ 상한 = K/2
```

### ★ 이것이 스크리닝 기준을 바꾼다 (가장 실무적인 결론)
지금까지 후보를 "챔피언보다 +15 나은가"로 걸렀다. **혼합 관점에서는 틀린 기준이다.**
```
K = 117.5 (계열이 다름)  →  d > −33.5 만 되어도 혼합 이득 +15   ← 33점 져도 채택
K =  45.6 (같은 계열)    →  d > +6.7  이어야 +15                ← 이겨야만 가치
```
**앞으로 모든 후보는 d 와 K 를 함께 재고 혼합 이득으로 판정한다.** K 는 저장된 .npy 로
학습 없이 즉시 잰다. d 만 보고 버리면 파트너를 놓친다.

당시 판단: "냉동 표가 없다(학습 표본에 가중치만 준다) → 전이 위험 낮음."
**틀렸다.** 위험은 세 축이고 셋 다 봐야 한다.

| 축 | 묻는 것 | 시즌 가중치 |
|---|---|---|
| 냉동 표 의존도 | 표가 2025에 낡는가 | 안전 (표가 없음) |
| 편향 vs 분산 | 8시드 앙상블에 먹히는가 | 안전 (순수 편향, 네 지표 일치) |
| **레짐 의존도** | **연도 관계가 반복되는가** | **최대 노출** ← 빠져 있었다 |

시즌 가중치는 "2024→2025 관계가 2023→2024 관계를 닮는다"에 거는 **레짐 베팅**이다.
로컬 하네스(≤2023 학습 → 2024 검증)는 그 가정을 검증할 수 없다. 정의상 그 가정 위에서
측정하기 때문이다. **paired σ 0.27은 시드 간 재현성이지 연도 간 전이성이 아니다.**
아무리 깨끗한 로컬 신호도 레짐 베팅이면 전이를 보장하지 않는다.

### 2-1b. 🚨 임계 +15는 **비짝지음** 기준이다 — paired σ를 직접 재라 (08-26 실증)

σ≈15.3은 **한 모델의 점수 산포**다. 짝지음 실험에서 재는 것은 **차이의 산포**이고
그건 훨씬 작을 수 있다. 고정 +15만 보면 진짜 이득을 버린다.

**실제로 판정이 뒤집힌 사례 — exp/69 A상 w_soft (시즌 가중치 0.8^age)**
```
              시드42          시드7        평균
  기준        830.9          831.2
  w_soft      838.2          839.3
  paired 차이  +7.3           +8.1        +7.7   ← paired σ ≈ 0.4
```
2시드·시드평균·proj8 이 **전부 정확히 +7.7**(= 순수 편향, 분산 성분 0)인데
고정 임계 +15로는 기각된다. paired σ가 0.4면 +7.7은 압도적으로 유의하다.
lr 축(2시드 +15.3 → 8시드 +3.8)과 정반대 성격이다 — 그쪽은 임계를 통과했지만 가짜였다.

**규칙**: 모든 짝지음 실험은 시드별 점수를 남기고, 판정은 **paired 차이의 평균과
산포**로 한다. 고정 임계는 시드별 점수가 없을 때의 대용품일 뿐이다.

### 2-4. 값싼 사전 게이트
```
모델 다양성: D = E[(p_A - p_B)²] 를 먼저 재라. 오차상관은 공통 y 때문에 항상 1에
  가깝지만 D는 y가 소거된다(e_A - e_B = p_A - p_B). 자체 보정: D가 HGB 시드간
  거리(1.27e-04)의 2배 미만이면 "추가 시드일 뿐" → 즉시 폐기. (LGBM이 이걸로 5분 사망)
혼합 수식: Δ = w(B_B - B_A) + w(w-1)D. 손실은 w에 선형, 다양성 이득은 w=0.5 최대.
  → 단독으로 지는 모델도 D가 크면 혼합에서 이긴다 (CatBoost가 정확히 이 사례).
★ D는 필요조건일 뿐 (TabM 교훈): D가 바닥의 27배여도 '틀린 모델'과의 다양성은 무가치.
  반드시 정상 해(2024) 폴드로 교차 확인. 혼합곡선이 격자 끝까지 단조 상승하면
  상보성이 아니라 수준 차이다 — 봉우리가 상보성의 증거.
배포 키: 새 피처마다 "2025 행에서 이 값이 NaN이 아닌가"를 먼저 확인 (exp/21-D 교훈).
```

### 2단계 설계 (exp/91b, 진행 중 — lab/runq91.ps1 로 B→D′ 큐)
Trackman 도착모델을 투수×상황 셀로 평균하면 그 셀의 경험적 영역 빈도로 수렴한다

## CODEX 읽기 전용 감사 — reverse-first 제안의 생존 여부와 게이트 교정 (08-30)

이 절에서는 **새 학습·배포·제출을 시작하지 않았다.** 저장된 `lab/89_cat5_probs_seed42.npy`와 정렬된 2024 분석표만으로 제안의 수식과 판정 논리를 감사했다.

- reverse-first는 M4·7클래스·CS reverse 피처·BIN04가 직접 검증한 질문이 아니다. `P(reverse)`와 `P(success|not reverse)`가 각각 별도 트리 구조를 갖게 하는 정확한 2-head factorization은 아직 미측정이다.
- 저장 확률에서 `qR5=p2+p3`, `qS5=p0/(p0+p1+p4)`를 계산한 결과 `max(abs((1-qR5)*qS5-p0))=3.56e-8`로 항등식 게이트를 통과한다.
- seed42의 2024 reverse 기준: 실제율 0.24803, `qR5` 평균 0.25323, Brier 0.183775(상수 0.186512), logloss 0.552710. reverse 자체 예측력은 있으나 크지는 않다.
- 중요한 상쇄 편향: non-reverse 실제 조건부 성공률은 0.64637인데 `qS5` 평균은 0.66411이다. `qR5`의 reverse 과대예측이 `qS5`의 성공 과대예측을 일부 상쇄하고 있다.
- 이를 확인하려고 2024 라벨로 `qR5`만 로지스틱 재보정한 **오라클 진단(배포 금지)**을 했다. reverse Brier 0.183775→0.183740, logloss 0.552710→0.552627로 개선됐지만, `qS5`를 고정한 본 점수는 **−35.62점** 악화됐다. 새 reverse head가 제대로 보정될수록 1-head `p_gate`의 중심은 오히려 나빠질 수 있다는 뜻이다.

### 따라서 기존 자동중단 규칙은 다음처럼 바꿔야 한다

1. reverse head 1차 게이트는 본 점수 +8이 아니라 **reverse Brier/logloss 개선 + `p_gate` 동일평균 shape gain ≥+5**로 판단한다. raw 본점수는 출력하되 qS head 진입의 필수조건으로 쓰지 않는다.
2. 위를 통과하면 두 번째 head를 학습한다: 학습행 `class∈{0,1,4}`만 사용하고 `y_cond=1[class==0]`; 이것이 정확한 `P(success|reverse=0)` 이진 head다.
3. 네 조합을 출력한다: 기존 `(qR5,qS5)`, reverse만 교체 `(qRnew,qS5)`, conditional만 교체 `(qR5,qSnew)`, 전체 계층 `(qRnew,qSnew)`. 그래야 어느 head가 이득/중심이동을 만드는지 분리된다.
4. 최종 성능 게이트는 후보 단독 +8만 보지 말고 **`max(단독 gain, d/K 해석적 혼합 gain)≥+8` + shape gain≥+5**로 한다. 예: d=+5,K=40이면 단독 +5여도 최적 혼합은 +12.7이므로 기존 규칙은 유효 후보를 오기각한다.
5. 제안의 `lr=.04`는 성능 탐색으로는 타당하지만 챔피언은 `.08`이므로 “공유 트리 구조만 격리”한 인과실험은 아니다. 결과 설명에는 `binary objective + 별도 트리 + lr 변경`의 합성 효과라고 적거나, 통과 후 `.08` 대조를 붙인다.

### 실행 순서 추가 교정 — 한 head만 먼저 돌린다면 conditional-first

- 2024 non-reverse 190,335행에서 실제 `P(success|not reverse)=0.64637`, 기존 `qS5` 평균=0.66411, Brier=0.227345(상수 0.228577), logloss=0.646924(상수 0.649667)이다. 조건부 head에도 독립적으로 개선할 여지가 있다.
- reverse binary가 제거하는 nuisance 구분은 `class2 vs class3`이고 class3은 전체 3.4%다. 반면 conditional binary는 `class1 vs class4`를 합치며 두 클래스 합계가 24.7%다. 성공확률에 불필요한 분류에 쓰는 용량을 더 많이 회수하는 쪽은 conditional head다.
- 중심 방향도 conditional 쪽이 유리하다. 챔피언 seed42는 성공확률을 +0.01005 과대예측하고 있고, `qS5`의 조건부 성공 과대예측은 이를 만드는 방향이다. 반대로 `qR5`의 reverse 과대예측은 현재 이 편향을 일부 상쇄한다.
- 따라서 실제 권고 순서는 **(1) `qSnew=P(success|not reverse)` head → `(qR5,qSnew)` 평가, (2) 통과 시 `qRnew` 추가 → 2×2 네 조합 평가**다. 사용자가 reverse를 먼저 실행하기로 결정하면 위 1~5의 shape 중심 게이트를 적용하고, raw `p_gate<+8`만으로 conditional head까지 죽이지 않는다.
